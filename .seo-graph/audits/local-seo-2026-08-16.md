- Thin pages created only to capture local long-tail searches.
- Lists of locations repeated across every page with no patient value.

Preferred approach:
- Use one strong homepage local signal.
- Use the existing consultation section as the canonical local access hub.
- Use structured data later to make approved locations machine-readable.
- Use condition pages for patient usefulness first, with light local context in metadata/internal linking if approved.
- If a location page is ever proposed, it should be a single helpful consultation/location guide, not town doorway pages.

Google context checked:
- Google's doorway-page guidance warns against pages created to rank for similar queries and funnel users to the same destination.
- Google's Search spam policies describe doorway abuse as pages created for specific, similar search queries that are not as useful as the final destination.
