# SCHEMA QA Gate

- [ ] Schema reflects only facts supported by the approved website or source material.
- [ ] No invented claims, ratings, reviews, awards, coordinates, sameAs URLs, credentials, outcomes, or locations.
- [ ] Physician/Person/MedicalBusiness/LocalBusiness/Article/WebSite/Breadcrumb schema is used only where appropriate.
- [ ] Schema does not contradict visible public content.
- [ ] Structured data validates where feasible.
- [ ] Lint, typecheck, and build pass when this node performs code changes.
- [ ] No commit, push, or deploy.
