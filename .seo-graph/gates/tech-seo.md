# TECH_SEO_QA Gate

- [ ] Lint passes.
- [ ] Typecheck passes.
- [ ] Production build passes.
- [ ] Indexable routes return expected success status.
- [ ] Redirect and utility routes behave intentionally.
- [ ] Robots and sitemap behavior are correct.
- [ ] Canonical URLs and metadata are coherent.
- [ ] Structured data validates where feasible.
- [ ] No broken internal links.
- [ ] No broken production images.
- [ ] No accidental noindex/nofollow.
- [ ] Mobile and Core Web Vitals risks visible from code/build are reviewed.
- [ ] No visual redesign or approved content mutation.
- [ ] No commit, push, or deploy.
